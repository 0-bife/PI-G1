# Requisitos Funcionais
* RN01 — Apenas administradores poderão cadastrar outros usuários.
* RN02 — Uma conversa poderá possuir somente um atendente responsável por vez.
* RN03 — Uma conversa finalizada poderá ser reaberta caso o cliente envie uma nova mensagem.
* RN04 — mensagens recebidas deverão ser associadas ao contato pelo número de telefone.
* RN05 — atendentes não poderão excluir o histórico de mensagens.
* RN06 — notas internas nunca poderão ser enviadas ao WhatsApp do cliente.
* RN07 — somente administradores poderão consultar determinadas configurações da integração.

# Requisitos Não Funcionais 
* RnF1 - Banco de Dados SQL
* RnF2 - Comunicação via API
* RnF3 - Versionamento com Git
* RnF4 - Autenticação
* RnF5 - Compliance com LGPD
* RnF6 - Criptografia de dados sensíveis
* RnF7 - Interface Web
* RnF8 - Código Aberto
